# 火焰猫燐（阿燐）角色卡

> 状态说明：**已确认** 为当前定案；**候选** 为待讨论方案；**待定** 为尚未确定、留待后续补充的内容。

## 一、基础人设与日常面貌

### 1. 日常生活与活动地点（已确认）
- **世界观前提**：口上中不直接描写“异变正在发生”（避免与其他角色口上发生剧情冲突）。
- **日常偏好地点**（对应移动倾向）：
  - **高偏好**：书房、蔷薇园、酒场、温泉。
    - *酒场 / 温泉*：贴合地底居民喜好与原作泡温泉设定。
    - *蔷薇园*：地灵殿的花园由她负责打理。
    - *书房*：设定为“对书有一定兴趣”（并非学识渊博，只是闲下来喜欢看看书），为后续剧情展开预留接口。
  - **次级偏好**：露台、河岸、桥等能静下心看风景歇息的地方。

### 2. 说话方式与称谓（已确认）
- **第一人称**：“咱”。
- **语气**：轻快、俏皮；只要玩家不做出出格举动，态度一直保持直爽友好。
- **对玩家的称呼**：
  - 初期：“小哥” / “大姐”（按玩家性别）。
  - 亲近后：直接称呼玩家的名字。

### 3. 生死观与玩笑底线（已确认）
- **死亡观**：对死亡的态度随意而亲近，这是她最核心的角色特色，需重点强调；但整体口上氛围保持正面，不写成“黑深残”。
- **对活人的态度**：用正常眼光看待活着的人类，不会像对尸体那样感兴趣，但可能会拿生死话题开玩笑。
- **玩笑底线**：除了关于死亡的底线非常低之外，其他方面的分寸感符合她性格的正常少女。

## 二、与主角的交集与关系推进

### 1. 初见与相识（已确认）
- **初始关系**：沿用主流设定，玩家是刚进入幻想乡的外来者；正式初见前双方不认识（阿燐可能对新的外来者有所耳闻）。
- **初见态度**：第一次见面时就会表现出对玩家特殊能力的兴趣，并以友好态度开始互动（但真正的亲近与信任仍需逐步建立）。

### 2. 日常互动与行为限制（已确认）
- **信任门槛（自定义限制）**：初期并不信任玩家，会拒绝一起做料理、采集、战斗训练、送礼、帮忙干活等深度互动，必须从聊天、泡茶等基础互动做起。
- **解锁后表现**：达到一定互动程度解锁上述行为后，代表初步建立友谊，反应转为随意自然。
- **喜好物品（待定）**：喜欢的料理、酒类、礼物等，待写到对应模块时再具体确定。

### 3. 路线与人际关系分量（已确认 / 部分待定）
- **路线定位（已确认）**：禁用“炮友—爱欲线”，只走“思慕—恋慕—恋人”纯爱路线。
- **生活实感与人际权重（已确认）**：营造阿燐“拥有自己生活”的实感。剧情初期需重点体现：
  - 对古明地觉的敬重
  - 与灵乌路空的深厚情谊
  - 对古明地恋的放不下心
  - 与橙、血枪等人的友谊
  - *目的*：让玩家后续逐渐进入她的生活时更有实感。
- **友情到恋情的转变（待定）**：需要专门的剧情设计，当前阶段暂缓细化。

## 三、对“时间停止（The World）”的处理

### 1. 整体定位（已确认）
- **纯爱向限制**：封锁前期的时停搬运、猥亵等“逃课/恶趣味”行为，仅将本体的时停内容保留为**后期的情趣玩法**。
- **正向呼应**：计划加入“玩家通过时停能力给予阿燐帮助、从而加快攻略进度”的入口，作为对游戏特色的呼应与对玩家的补偿。

### 2. 剧情自洽方案（已确认框架 / 细节待定）
- **核心机制**：阿燐从一开始就知道（或察觉）玩家拥有特殊能力，在时停中也能用火焰保护自己，使玩家无法靠近。
- **知情途径**：
  - **地底开局（已确认）**：古明地觉通过读心预先得知玩家拥有时停能力，并告知阿燐。
  - **非地底开局（已确认）**：初见时即挑明（避免后续大量函数反复检测知情状态）。理由为阿燐凭借“猫的直觉”感知到玩家身上存在时间异常的气息，结合原作中她与十六夜咲夜互动过的经历，看出玩家身上有与咲夜相似的感觉，从而推测出玩家拥有时停能力。
