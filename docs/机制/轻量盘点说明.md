# 第一轮轻量盘点说明

日期：2026-11-12。范围为根目录7个ERB和1个ERH。遍历全部标签、函数体和声明，结合关键片段阅读、词面引用检索及当前中文模板的局部比较，形成40个候选审查单元。

本轮不运行游戏、不改ERB/ERH、不作失效裁定。154个标签包含SKIP区中的标签，不是实际加载函数数；40项包含模板、工具、调试及预留内容，不是40个独立完成机制。详情见 [机制总表](机制总表.md)，全部标签与快照见 [源码索引](轻量盘点源码索引.md)。

## 主要依赖与时序线索

以下箭头表示已见的代码数据联系或调用，不代表当前本体已验证会按预期时点触发全部入口。

- **初始化**：UPDATE与日初入口 → `AME36_INIT` → `AME36_FIRSTTIME(0)` → 属性与先天状态写入。日初入口另用FIRSTTIME(3)作切换警告。M002先核对这一范围；注册/版本（M001）和槽位（M040）作为必要依赖。
- **关系成长**：SOURCE中的次数与经验处理（M007）→ 指令记录（M006）；陪伴值（M008）→ EVENT31日末相守值 → 回忆贡献。酒/料理位图（M009）及道歉状态（M010）也进入回忆汇总；回忆汇总写BREAKTHROUGH → EVENT31相识取得（M005）。阶段读取又限制回忆贡献与有效值，存在反馈关系。
- **好感与SOURCE**：各指令基础值 → 成败分歧 → 好感信赖初值 → 有效回忆倍率 → 抵消本体补正 → 每日递减。临时好感信赖由MARKCNG相关接口写入本体值，再在FLAGSETTING显示、清零。M011与M012需共同核对处理时点。
- **非目标PALAM**：FLAGSETTING保存快照并清IS_TARGET → EXTRASOURCE标记目标 → 日记BEFORE_CHECK决定回滚（M013）。该功能实际依赖日记入口，日记尚未写正文不代表它没有用途。
- **指令限制**：SUCCESS（M015）→ COM298替身或保存原行动并临时设睡眠 → EXTRASOURCE恢复行动；SUPPRESSION_TRIGGER又连接FLAGSETTING的情绪理性恢复（M014）。必须检查异常退出和恢复顺序。
- **日末积攒度**：EVENT31调整经验、保存积攒度并置零 → 日记EXIST恢复（M018）。与M008/M005共用日末入口，审查时不能只读其中一段。
- **移动与服务**：日初重置请假计数 → 猫车COM271（M022）→ 请假分支（M023）；地图/工作判断、时间和角色位置写入需核对本体副作用。CHARADATA移动与危险判定（M019）、旧GRAVITY停用入口（M037）分开记录。
- **界面**：COM299（M024）读回忆计算、酒与料理位图，并调用完成度输出；DQ（M030）、AA/报错/清屏（M031）作为独立工具登记，不假定已被剧情接入。

## 模板与占位处理

- EVENTCOM已在模板初评中全文归一化比较相同；本轮再次将7个空入口归入M036。
- 源码索引对所有标签执行同名占位符归一化匹配，并比较去注释、声明和空白后的函数体。这只用于定位疑似模板内容；不作为完整语义等价、参数一致或原始历史来源证明。
- M034集中登记初见、SP_EVENT、常规EVENT1～34及送礼、斗虫、打西瓜、契约、房间说明、许可、委托等剩余骨架，不把注释描述的本体行为算作自定义实现。M010的EVENT29、M005/M008/M018/M032的EVENT31等实际逻辑已拆出。
- 骨架中的固定RETURN也可能影响本体控制流。M027的ONABARE固定返回、M026的MESSAGECHECK和M039保留占位符的示例优先核对；不能因“待写”就直接删除。
- `AME36_FALL_EX`固定返回0暂归M005；`AME36_FOLLOWABLE`本身有实现，但已见的平日跟随使用处被注释，归M019记录。工具存在不等于使用场景已完成。
- 钱包/创伤/反感三个别名在8个文件的去注释词面检索中仅有声明（M033）。这只是预留线索，后续仍须查数字槽位、动态访问和本体读写。

## 快照与复查方式

口上提交仍为 `fd0c7c7`；开始时只有未跟踪的docs目录。本轮创建盘点文档及 `tmp/轻量盘点.py`。脚本只读取根目录ERB/ERH及已定位的模板，输出本记录区的源码索引；不修改游戏或authoring。
