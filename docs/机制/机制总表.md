## 状态约定

- **类型**：实际实现（含工具和基础设施）、空模板/占位、停用代码、调试辅助、声明预留；同一候选项可含多种类型。实际实现仅表示有具体代码，不表示接入有效或全部写完；无法确认时标为待确认。
- **源码审查**：待审查、审查中、已核对、需复查。已核对表示本项计划内的源码核对已完成，仍须阅读条目的结论及局限。
- **运行验证**：未验证、部分验证、已验证；具体场景和结果写入条目，不能仅凭“已验证”推定全部路径通过。
- **处理决定**：未决定、保留、待修复、待替换、待退役，或相应的已处理状态。建议尚未确定时注明“建议”，不当作既定决定。

源码审查、运行验证与处理决定互相独立。例如可以是“已核对 / 未验证 / 建议保留”。

审查队列和未确定问题见 [待定事项](待定事项.md)，记录方法见 [记录区入口](README.md)。
